# Импорт годовой истории и суточные признаки

## Запуск

Из корня репозитория после установки зависимостей. Архивы сначала распакуйте; импортёр принимает CSV, а не 7z.

```powershell
$annualSources = Get-ChildItem data/raw/ext-journal-*.csv | Sort-Object Name | ForEach-Object { $_.FullName }
python -m app.ingest --database data/warehouse/history.duckdb --report data/warehouse/ingest.json @annualSources
python -m app.features --database data/warehouse/history.duckdb --output data/warehouse/daily_features.parquet --catalog data/raw/справочник_каналов_датчиков.csv
```

В bash передайте `data/raw/ext-journal-*.csv` непосредственно вместо массива PowerShell.
DuckDB ограничен 3 GB памяти для операций и четырьмя потоками; временные файлы могут занимать дополнительное место на диске. RSS процесса может превышать этот лимит. Запускайте импорт последовательно, без других писателей в ту же БД.

## Контракт хранения

- Один файл коммитится одной транзакцией. Ошибка не оставляет частично импортированный источник.
- SHA-256 содержимого служит идентификатором источника. Повторный запуск пропускает уже принятые байты независимо от имени; другой часовой пояс для того же источника отклоняется.
- Ключ происхождения — source_sha256 + source_row (номер CSV-записи после внешнего заголовка). source_row сохраняет первую запись группы точных повторов; occurrences — их количество.
- Внутри файла группируются только совпадающие значения всех шести исходных CSV-полей. Повторный ID с другим содержимым сохраняется, даже если время совпадает.
- Строки с невалидным ID, временем или тревожным флагом сохраняются в rejects_<sha256> с причиной и исходными полями. Структурно повреждённый CSV отклоняется целиком.
- Встроенный заголовок исключается только при совпадении всех шести полей.
- events — представление нормализованных событий; ingest_sources — журнал происхождения и счётчиков; daily_channels — агрегаты канал/локальный день/источник.
- Московский пояс — явное допущение для этих выгрузок. event_time хранит момент времени, local_date — календарный день источника.

Сверка: raw_rows = embedded_headers + accepted_rows + exact_duplicate_rows + rejected_source_rows.
ambiguous_event_ids относится к нескольким разным строкам с одним ID внутри файла. Это признак неоднозначности, не автоматическая причина удалить событие.

## Ограничения объединения источников

Между различающимися файлами автоматической дедупликации нет. Повторяющиеся ID между годами сохраняются. Если два файла содержат один канал в один день, экспорт признаков останавливается: пересекающиеся выгрузки сначала нужно согласовать. Поэтому не смешивайте годовую историю с повторной копией её дней из примера.

## Признаки и время доступности

Parquet содержит только наблюдавшиеся канал-дни: число событий и тревог, долю тревог, тип датчика из переданного справочника, дату предыдущего наблюдения и разрыв в днях, суммы за предыдущие 7/30 календарных дней, число наблюдавшихся дней и медиану активности канала за предыдущие 30 дней.

Текущий день не входит в предыдущие окна. feature_available_at — следующая локальная полночь: суточные признаки нельзя использовать для прогноза в начале того же дня. activity_ratio_to_past сравнивает текущий день только с прошлой медианой канала. baseline_available требует хотя бы 7 наблюдавшихся прошлых дней; это инженерный порог, не доказанный критерий качества.

Дни без событий не подменяются нулевой активностью или исправностью. Неизвестный тип остаётся NULL. Текущий справочник не доказывает историческую принадлежность канала. Целевая метка отказа не создаётся: target_available=false.

## Проверки

Тесты покрывают идемпотентность, откат повреждённой схемы, сохранение совпадающих ID, карантин, точные повторы, часовой пояс, запрет пересекающихся выгрузок и неизменность прошлых признаков при изменении будущих событий. Фактический прогон на годовых данных фиксируется в analysis/ingest_report.json; отчёт обновляется после каждого завершённого года.

Веб-MVP пока продолжает читать демонстрационный CSV. Подключение этого хранилища к API и валидация модели — отдельный следующий этап.
