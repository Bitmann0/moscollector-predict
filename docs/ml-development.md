# Воспроизводимый ML-эксперимент

Первый обучаемый эксперимент находится в `backend/ml` и не меняет API веб-сервиса.
Он прогнозирует наличие записи «Неисправен» у насосов в следующие сутки после суток
без неё. Это слабая разметка технических сигналов, не подтверждение физических отказов.

## Запуск

Из корня проекта, Python 3.12, исходные архивы остаются локальными:

```bash
python3 -m venv .venv-ml
.venv-ml/bin/pip install -r requirements-ml.txt
.venv-ml/bin/python -m ml.prepare
OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 .venv-ml/bin/python -m ml.backtest
.venv-ml/bin/python -m ml.publish
```

`ml.prepare` берёт 2024–2026 годы из `dataset.zip`, распаковывает выбранные годы
в `analysis/extracted`, потоково читает CSV через DuckDB и пишет суточные агрегации
в `data/processed/pumps`. Требуется примерно 8 GB свободного места для выбранных
архивов и CSV, плюс временная память обработки. Бюджет DuckDB — 2 GB.

Справочник: `data/raw/справочник_каналов_датчиков.csv`. Пути можно переопределить
через CLI (`--help`). Обработка исходников выполняется только на чтение. Повторный
запуск пересоздаёт производные таблицы и отчёты по заданным выходным путям.

## Проверяемость

- Сохраняются SHA-256 источников, агрегаций, версии библиотек и интервалы разбиения.
- Одинаковые наблюдения удаляются по каналу, timestamp, флагу и значению, а не по ID.
- Невалидные строки подсчитаны в `rejected_rows` манифеста; это не успешные наблюдения.
- Последовательность состояний внутри одной секунды не выдумывается.
- Отсутствие будущей телеметрии исключает точку из оценки, а не создаёт отрицательный класс.
- Тесты проверяют неизменность прошлых признаков при изменении будущих данных,
  исключение разрывов и обрезание целевого окна на границах выборок.

`data/models/pump-signal-v1/model.joblib` — локальный обученный артефакт; не загружайте
joblib-файлы из недоверенных источников. CSV с индивидуальными тестовыми оценками
и производные данные исключены из Git. В `docs/experiments/pump-signal-v1` публикуются
только агрегированный отчёт и происхождение данных.

## Интерпретация

Сравниваются логистическая регрессия и градиентный бустинг. Модель выбирается по
Average Precision на январе–сентябре 2025. Порог выбирается на октябре–декабре 2025;
если Precision > 0,7 недостижим при минимум 10 уведомлениях, применяется заранее
заданный максимум F0.5 с явной отметкой неуспеха. Финальный тест — январь–июнь 2026.
Подбор на этом тесте не выполняется. Новые версии после его просмотра должны
обозначать повторное использование теста либо получать независимый holdout.

У этого кандидата пока недостаточно качества для автоматического использования
в диспетчерской системе. Исходный результат: [отчёт](experiments/pump-signal-v1/README.md).
