# Архитектура версии 0.2

FastAPI при старте загружает пример событий CSV и справочник каналов. Валидация проверяет обязательные поля, идентификаторы, время, тревожные флаги и конфликты справочника. Удаляются точные повторы строк и встроенные заголовки. Одинаковые ID с разными событиями сохраняются; счётчики качества доступны в метаданных.

Pandas строит признаки за окно до последнего события и эвристический индекс проверки. Интервалы считаются по различным временным отметкам канала. Индекс зависит от частоты событий и типа канала; качество обнаружения отказов не подтверждено.

Оценки находятся в памяти. SQLite хранит черновики, режим анализа и дату данных. Миграция добавляет поля в существующую БД; старые записи получают режим legacy. Черновик другого режима нельзя переиспользовать как текущий. Статусы и история решений пока не реализованы.

Статический UI показывает оценки, условную схему каналов и журнал черновиков. Координаты и связь каналов с объектами не установлены. Данные CSV экранируются при вставке в HTML.

Docker запускает сервис без root. Новый том /app/state доступен пользователю приложения. Для существующего тома с чужим владельцем может потребоваться исправление прав: сборка образа не меняет существующие файлы тома. Healthcheck проверяет /api/v1/ready.

Годовые архивы, XLSX, поток СМВУ и справочник объектов пока не подключены. Обновление CSV требует перезапуска. Аутентификация, права доступа и эксплуатационный аудит отсутствуют.
