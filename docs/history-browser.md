# Просмотр годовой истории в сервисе

Сначала создайте daily_features.parquet по инструкции [annual-ingestion.md](annual-ingestion.md).
Укажите MOSCOLLECTOR_HISTORY_FEATURES — путь к файлу — перед запуском Uvicorn.
В Compose каталог data/warehouse уже подключён только для чтения, ожидается файл daily_features.parquet.

Раздел «Годовая история» показывает общий период, число каналов и наблюдавшихся канал-дней. Можно выбрать дату, отфильтровать канал, переключать страницы и открыть последние 30 календарных дней канала. Пропущенные дни считаются неизвестными и явно подсчитываются.

Таблица сравнивает число событий с медианой предыдущих 30 календарных дней того же канала. Коэффициент показывается при наличии хотя бы 7 наблюдавшихся прошлых дней. Это сравнение активности, не вероятность отказа и не сигнал необходимости ремонта. Отсутствующие исторические каналы не заменяются сегодняшним справочником объектов.

## API

- GET /api/v1/history/summary — границы и объём доступной истории.
- GET /api/v1/history/days?day=2026-06-30&channel=104049&limit=100&offset=0 — показатели выбранного дня; channel необязателен.
- GET /api/v1/history/channels/104049?end=2026-06-30&days=30 — наблюдения канала за календарный интервал, число дней с данными и без них.

Ошибочная дата или размер страницы дают 422. День без наблюдений возвращает пустой список. Неподключённая или повреждённая история даёт 503. Этот архивный раздел доступен независимо от загрузки демонстрационного CSV; основной /ready продолжает описывать готовность текущего анализа MVP.

Запросы читают подготовленный Parquet, не перебирают исходные 313 млн строк. Импорт и создание признаков выполняются отдельно. Все запросы архива только читают данные; черновики из архивных строк не создаются.

## Проверка

36 тестов проходят. Браузерная проверка выполнена на полном наборе: выбор даты, пагинация (2 716 каналов за 30 июня 2026), фильтр пустого дня и карточка канала 104049 (17 наблюдавшихся дней и 13 дней без наблюдений за июнь). Ошибок JavaScript при проверке не обнаружено.
